# RentSmart - R.M Imóveis 🏠

Sistema desenvolvido em Python para automatizar o cálculo de orçamentos de locação de imóveis (Casas, Apartamentos e Estúdios) utilizando os fundamentos da Programação Orientada a Objetos (POO).

## Funcionalidades
- Interface interativa via terminal.
- Validação de dados do usuário.
- Aplicação automática de regras de negócio (adicionais, descontos por filhos, regras de garagem).
- Separação clara entre aluguel mensal e taxa contratual.
- Geração automática de arquivo `.csv` com a projeção financeira dos 12 primeiros meses.

## Como executar o projeto

1. Certifique-se de ter o Python 3 instalado em sua máquina.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal e navegue até a pasta do projeto.
4. Execute o arquivo principal com o comando:
   ```bash
   python3 main.py
